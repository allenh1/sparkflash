Setup

Seven steps from four Sparks to a running server. Every step checks itself, so you can close this page and come back.

  1. 1

    Find your Sparks

    Pick the three Sparks that work with this one.

  2. 2

    Connect the fast network

    Check the cables between the Sparks and set up their fast ports.

  3. 3

    Install on the other Sparks

    Copy the server program from this Spark to the others.

  4. 4

    Download the model

    Fetch the model from Hugging Face onto this Spark.

  5. 5

    Copy the model to the other Sparks

    Send the model over the fast network, so it is downloaded only once.

  6. 6

    Prepare the weights

    Each Spark converts its quarter of the model for the GPU.

  7. 7

    Start the server

    Load the model on all four Sparks and answer requests.
