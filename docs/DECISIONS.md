# Decisions

**This file is the decision register, not a journal.** Each row is a stable ID and a decision
summary. The full evidence and consequence for every entry is preserved in
[`docs/archive/decisions-full.md`](archive/decisions-full.md) and is not maintained.

- Operational rules (measurement, gates, review, docs) live in [`docs/RULES.md`](RULES.md). If a
  decision row and `RULES.md` disagree on process, `RULES.md` wins.
- IDs are stable. Source comments cite them (for example `DECISIONS.md D26`); they are never
  renumbered.
- A row that says "superseded" keeps its ID: the replacement is named in the row.
