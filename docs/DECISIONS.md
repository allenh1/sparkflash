# Decisions

**This file is the decision register, not a journal.** Each row is a stable ID and a decision
summary. Fuller evidence for the early entries lived in design records that were removed before
release; they remain in the git history.

- IDs are stable. Source comments cite them (for example `DECISIONS.md D26`); they are never
  renumbered.
- A row that says "superseded" keeps its ID: the replacement is named in the row.
