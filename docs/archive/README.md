# Archive

Historical records kept for provenance. They contain superseded numbers, rules and plans and are
**not maintained**. Current documentation is in [`../RULES.md`](../RULES.md),
[`../DECISIONS.md`](../DECISIONS.md), [`../build/`](../build/) and [`../architecture/`](../architecture/).

| Directory / file | Contents |
| :-- | :-- |
| `build/` | The old `docs/build/` tree: phase-3 kernel harnesses, device/speed-track windows, serving and TP=4 plans, D38/D41/D48 protocols, fabric bring-up, build records. 140+ files, including the S1 device-port window records (`s1-p*.md`, `s1-qa-harness.md`) and the 2026-10-23 S1-0 probe bundle (`s1-device-probe-20261023/`). |
| `build/task32-evidence-README.md`, `build/task53-evidence-README.md` | The old READMEs for the evidence bundles that remain under `docs/build/`. |
| `decisions-full.md` | The full D1-D54 decision log with evidence and consequences. The current register is [`../DECISIONS.md`](../DECISIONS.md). |
| `RULES-speed.md` | The 2026-10-21 speed-track rules, superseded by [`../RULES.md`](../RULES.md). |
| `QUALIFICATION.md` | The Milestone-5 qualification runbook (2026-10-15), superseded by [`../build/operations.md`](../build/operations.md). |
| `investigations/` | DeepInfer and `deepseek-recipe` source surveys. Useful background; their process conclusions predate D54. |

The filename is the subject in almost every case. Use `grep` if you need a specific old decision or
measurement. Do not link an archived page from a current handbook unless the link is explicitly
historical.
