# P0 final per-layer per-block timing with kernel/host split (probe v2)

Status: measurement table only. No tok/s, TTFT or acceptance claim is made here; the M2
target stays a separate gate and this table does not satisfy it.

Evidence: probe-v2 perf rows (schema sparkflash-tp4-forward-perf/2), four ranks each, kit m1w37.
Source commit: 12ce66787b7590c80b3f7f2c81c772408b4a2df5.
Every block row is the probe's 18-field array (legend.block_fields); wall_ms is host wall around
the block with the driver draining the context, kernel_ns is the summed cuEventElapsedTime of the
launches in it, staging_ms is the sum of the h2d/d2h/dtod copy walls, host_sync_ms is the host wall
inside the per-launch drains, and host_residual_ms is wall - staging - sync (host code plus the
launch path that is neither a copy nor a drain). kernel_ms sits inside the drain, so the columns are
not additive; run.probe_overhead prices the probe's own boundary drain and is excluded from block walls.
